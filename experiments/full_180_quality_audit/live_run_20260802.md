tasks: six environments, five skill families per environment, and T1--T6 per
family. “Five” means five evidence lanes over those tasks:

| Lane | Coverage | Cells |
|---|---:|---:|

inside one agent session, so the 630 cells expand to 630--810 task attempts.
Flagged cells receive manual semantic review and, for critical conclusions,
three valid repeated samples. They are not removed from the 180-row ledger.

## Evidence acceptance rule

AP `Succeeded` is never accepted by itself. A cell enters the final ledger only
after exact task ID, dataset split, benchmark revision, Agent-Hub template
commit, verifier evidence, attempt ledger, condition-specific skill view,
canonical trajectory/session export, runtime pruning provenance, and
secret-free download all validate. Transport-null rows are reported separately
and never scored as model or skill failures.
